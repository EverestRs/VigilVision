## 1. 项目概述

### 1.1 背景

| 项 | 内容 |
|---|---|
| 赛事 | 第十六届中国大学生服务外包创新创业大赛（A 类赛题，A28） |
| 命题单位 | 西安电子科技大学 |
| 题目方向 | 智能计算 |
| 核心任务 | 基于校园监控视频，实现人员行为智能感知与异常事件实时预警 |
| 数据约束 | 因隐私合规，命题方仅提供约 5 分钟测试数据；无可用于监督训练的人工标注 |

另有一条并行赛事线（传智杯 AIoT 嵌入式系统创新大赛，边缘单盒版），见 [04 边缘化与参赛](04_EDGE_AIOT.md)。

### 1.2 产品定位

**慧眼智警**是一套**开放式视频事件感知与告警平台**：对视频流实时完成人员检测、跟踪、姿态估计与行为识别，支持 11 类内置行为，并允许用户**用一句自然语言动态定义任意新告警规则**，最终在本地完成"告警触发 → 证据留存 → 事件裁决 → 历史检索"的完整闭环。

三条核心设计主线：

1. **VLM-as-Teacher 弱监督**：用本地 Qwen2.5-VL 作为"教师"为未标注视频生成伪标签，训练轻量姿态序列分类器（PoseClassifier），实现**零人工标注**的行为识别主路径；
2. **分层开放行为识别**：轻量闭集主路径保证毫秒级实时性，大模型开放词汇复核保证对任意长尾事件的开放性——用分层架构化解"实时"与"开放"的矛盾；
3. **全本地部署**：检测/姿态/行为全程 ONNX CPU 推理，大模型走本地 vLLM 服务，视频数据不出域，满足校园/园区/养老等隐私合规刚需。

### 1.3 核心能力摘要（真实评估）

| 指标 | 数值 | 说明 |
|---|---|---|
| 主路径准确率 | 85.7%（entrance_3）/ 77.7%（corner_3） | VLM 伪真值口径，存在乐观偏差 |
| 对比零样本基线 | +19.1pp（entrance_3） | 基线 = SlowFast 关键词映射 66.6% |
| 人工金标口径 | 准确率 94.4% / Macro-F1 0.971 | 89 条人工金标，独立锚点 |
| 开放事件命中率 | 78%（挥手 100% / 握手 88% / 投掷 75% / 鼓掌 50%） | HMDB51 四类训练体系外行为 |
| 跌倒误报抑制 | 89 次 → 6 次 | 强制 VLM 复核 |
| 主路径推理 | ~10ms/帧 | PoseClassifier ONNX，CPU |
| 全流水线延迟 | 363ms 均值 / 631ms p95 / 2.8fps | bench300 基线，realtime 档 |

## 2. 行为识别类别体系

系统为 **11 类闭集**（Normal + 10 种异常），按风险分三级。下表同时给出**当前代码实际走的识别路径**（模型出候选、规则补位置、VLM 做确认）：

### 2.1 高风险异常（Priority 1）

| ID | 名称 | 定义特征 | 当前实现路径 | 可靠性 |
|---|---|---|---|---|
| H01 | 打架斗殴（互殴） | 双向对抗性肢体攻击：推搡、挥拳、踢打、扭打 | PoseClassifier 主路径 + 灰区 VLM 复核；InteractionAnalyzer 角色区分 | 中（训练 140 条） |
| H02 | 校园霸凌（单向攻击） | 多方对单方持续攻击，被攻击方被动防御/倒地 | 同上，角色区分是难点 | 低（训练 6 条，原型层覆盖） |
| H03 | 跌倒/昏厥 | 突然倒地且短时间无法自行站起 | PoseClassifier + **强制 VLM 复核**（无论置信度高低） | 中高（训练 150+2485 增量） |
| H04 | 疑似轻生/极端危险 | 撞墙、翻越栏杆危险停留、自缢动作 | PoseClassifier + 灰区复核 + danger_zones 危险区规则 | 低（训练 8 条） |
| H05 | 破坏公共设施 | 踢踹门窗、砸物、破坏设备 | PoseClassifier（训练 14 条）+ SlowFast 回退 | 极低（靠回退） |

### 2.2 管理敏感（Priority 2）

| ID | 名称 | 定义特征 | 当前实现路径 | 可靠性 |
|---|---|---|---|---|
| M01 | 吸烟/点火 | 点火动作、吸烟姿态、烟具使用 | 三重：①吸烟姿态规则（鼻尖-手部距离，连续 10 帧，0.72 落灰区）②**强制 VLM 复核**③PoseClassifier（训练 1502 条） | 中高（近距）；远距 75–150px 为 7B 感知极限 |
| M02 | 长时间使用手机 | 手持贴耳通话或长时间专注操作 | PoseClassifier + 灰区复核 + phone_posture_rule | 召回偏低（双口径实测 P=0） |
| M03 | 遮挡/干扰摄像头 | 遮挡镜头、喷涂、移动摄像头 | SlowFast 关键词回退 + infer() 遮挡规则 | 极低（训练 7 条） |

### 2.3 可疑行为（Priority 3）

| ID | 名称 | 定义特征 | 当前实现路径 | 可靠性 |
|---|---|---|---|---|
| S01 | 异常徘徊/滞留 | 门口/楼梯口/围栏反复来回、超时停留 | **仅由轨迹规则产生**（refine_light）：45s 视频时间窗口 + 活动半径 + 路径/位移比；模型输出的 S01 一律重映射 Normal | 高（规则明确） |
| S02 | 翻越围栏/闯入禁区 | 跨越围栏、进入禁止通行区域 | 位置规则（forbidden_zones 多边形）+ 布控区域绘制 UI + REST 热更新 | 几何可靠（无训练样本） |

> **口径提示**：11 类中训练数据充足的只有 Normal/M01/M02/H03/H01 五类；H05/M03/S02 主路径结构上无法输出，由回退/规则/开放词汇覆盖。材料中应如实表述覆盖策略，分列三类指标。

### 2.4 体系外行为（开放词汇）

固定 11 类无法覆盖任意长尾事件，因此设一级**开放词汇通道**：用户一句话定义规则 → 闭集映射（命中 11 类则零成本逐帧）或 VLM 关键帧判定（体系外）。已验证四类训练未见行为（挥手/鼓掌/投掷/握手）总体命中 78%。详见 [02 §5.2](02_ARCHITECTURE.md)。

### 3.2 识别流程（当前实现）

```
帧输入 → Detector(YOLOv8n) + Tracker(ByteTrack)
       → PoseEstimator(ViTPose WholeBody 133 点)
       → PoseClassifier 主路径(32 帧姿态序列 → 11 类, ~10ms CPU)
         ├─ conf ≥ 0.75          直接采纳
         ├─ 0.40 ≤ conf < 0.75    VLM 灰区复核（场景上下文 + 行为序列注入）
         └─ conf < 0.40           SlowFast 关键词映射回退
       → 强制 VLM 复核（H03/M01，person crop 高清帧，25 帧节流）
       → BehaviorReasoner.refine_light 规则修正（S01 徘徊 / S02 禁区 / M01 吸烟姿态）
       → InteractionAnalyzer 角色区分 → TemporalAdjudicator 时域裁决（默认关）
       → AlertSystem 告警 + NLAlertRuleEngine 开放词汇 → AlertAdjudicator 裁决
       → SceneNarrator 叙述 → SceneIndex 检索 → FastAPI/WebSocket/Streamlit
```

三级决策策略：

| 置信度区间 | 决策路径 | 延迟 | 适用场景 |
|---|---|---|---|
| ≥ 0.75 | PoseClassifier 直接采纳 | ~10ms（CPU） | 大部分清晰样本 |
| 0.40–0.75 | VLM 3 帧复核（异步） | 秒级（后台回写） | 模糊/歧义样本，约 10–15% 帧 |
| < 0.40 | SlowFast 关键词映射回退 | ~200ms（CPU） | 长尾/罕见样本 |

## 5. 数据策略

### 5.1 约束与三条路径

命题方仅提供约 5 分钟测试数据，无标注训练集。系统依次采用：

1. **预训练模型 + 零样本映射**：YOLOv8n（COCO person）、ViTPose WholeBody（133 点）、SlowFast（Kinetics-400 → 关键词映射 11 类）——无需训练数据即可联调；
2. **VLM-as-Teacher 弱监督**（已实施，主路径）：Qwen2.5-VL 生成伪标签 → 训练 PoseClassifier；
3. **启发式规则补充**：位置/轨迹类行为（S01 徘徊、S02 禁区、M01 吸烟姿态）由规则引擎兜底。

### 5.2 VLM-as-Teacher 弱监督方案

**动机**（真实数据）：人工抽检 326 帧，零样本 SlowFast + 规则引擎准确率仅约 50%；laying 视频大量误报 H01/H02；400→11 类关键词映射存在固有信息损失。

**三阶段流水线**：

```
Phase 1  VLM 伪标签生成（离线，vLLM）
  19 个视频，按 60 帧间隔采样 person crop（3 帧时序）
  Qwen2.5-VL-7B 输出 {label, confidence, reasoning}，conf ≥ 0.6 过滤
  → 与姿态序列对齐，生成 NPZ (N, 32, 133, 3)

Phase 2  PoseClassifier 训练（GPU V100）
  空间编码器(MLP) → 双向 GRU(2 层, hidden 256) → 分类头 → 11 类
  加权 CrossEntropy（逆频加权 clip 0.5–10）、AdamW、CosineAnnealing、100 epoch
  导出 ONNX（opset 17，动态 batch），CPU ~10ms/帧

Phase 3  三级融合推理（运行时）
  PC ≥0.75 采纳 / 0.40–0.75 VLM 复核 / <0.40 SlowFast 回退
  BehaviorReasoner 仅保留位置相关规则
```

**教师 Prompt（中文，3 帧时序）**：

```
你是一个校园安防视频分析专家。以下三帧是连续监控画面（时间顺序从左到右）。
请分析红色框内人员的行为。选项：
- Normal: 正常行走/站立/坐姿，无异常行为
- H01: 打架斗殴，双向对抗性肢体攻击
- H02: 校园霸凌，单方对另一方持续攻击
- H03: 跌倒/昏厥，突然倒地且无法自行站起
- H04: 疑似轻生，翻越栏杆/撞墙等极端危险行为
- H05: 破坏设施，踢踹门窗/砸物
- M01: 吸烟，手持烟具靠近嘴部
- M02: 使用手机，手持电话贴耳或低头操作
- M03: 遮挡摄像头，用手/物体遮挡镜头
- S01: 异常徘徊，同一区域反复来回
- S02: 翻越围栏/闯入禁区
请仅输出JSON: {"label": "H01", "confidence": 0.95, "reasoning": "..."}
```

**伪标签实际分布（23,637 样本）**：

| 类别 | Normal | M02 | M01 | H03 | H01 | H05 | H04 | M03 | H02 | S01 |
|---|---|---|---|---|---|---|---|---|---|---|
| 样本数 | 22,543 | 488 | 279→1502* | 150 | 140 | 14 | 8 | 7 | 6 | 2 |

\* M01 经 2026-09 重标（改进 prompt + person crop）从 279 补到 1502。教师把 93% 的 smoking 帧判为"画面中无吸烟动作"，这是 M01 欠采样的根因，也是"教师质量决定上限"的直接证据。

**教师已知偏差**（必须在材料中披露）：
- 教师置信度恒为 0.9，无区分度；
- 同类教师既当老师又当考官 → 伪真值指标存在乐观偏差；
- 小目标（bbox 75–150px）判定 50/50 抖动，属 7B 感知极限而非工程问题。

### 5.3 数据增强（规划/训练侧已用）

空间（随机裁剪、旋转、透视）、时序（时间裁剪、速度变化、帧采样）、光照（亮度/对比度/噪声）、遮挡模拟。注意训练侧 2026-09 曾因 `np.clip(pose,-1,1)` 摧毁未归一化像素坐标（已修，见 03）。

### 6.2 安全与隐私

| 项目 | 状态 |
|---|---|

## 8. 风险与应对（当前状态）

| 风险 | 影响 | 应对 | 现状 |
|---|---|---|---|
| 训练数据不足 | 泛化差 | 预训练零样本 + VLM 伪标签 + 规则 | ✅ 已落地，长尾类仍缺数据 |
| CPU 实时性 | 达不到 300ms | INT8 + 帧跳步 + 多线程 + B6 三阶段流水线 | ⚠️ p95 631ms（含灰区 VLM）；异步化后 p50 已降至 ~400ms 级 |
| 角色区分困难 | 无法区分互殴/霸凌 | 姿态活动度 + 防御姿态规则 | ⚠️ 未验证，仅展示 |
| 类别不匹配 | Kinetics-400 ≠ 校园 | 关键词映射 + PoseClassifier 替代 | ✅ 主路径已替代映射 |
| 开源合规 | AGPL 风险 | 如实署名；商用前评估替换 | ⚠️ YOLOv8 为 AGPL |
| 单路处理 | 无法多摄像头 | 后续里程碑 | ❌ 未做 |
| API 无认证 | 公网暴露风险 | 演示环境隔离 | ⚠️ 待做 |
| 无视频切片 | 无法回溯现场 | 已有截图 + 事件 JSON | ⚠️ 部分满足 |
